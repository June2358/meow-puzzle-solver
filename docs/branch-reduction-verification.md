# 분기와 중복 축소 검증 — 2026-10-24

기준 커밋은 `b230536`이다. 퍼즐 규칙·기법 우선순위·풀이 기록을 보존하면서
여러 곳에 반복된 판정과 좌표 계산을 하나의 구현으로 모았다.

## 통합한 구현

- Sudoku pointing/claiming과 MEOW 영역↔행/열 잠금이
  `puzzle_common.constraints.locked_candidate_targets()`를 공유한다.
  최소 근거 수와 이미 놓인 고양이 확인, 설명과 기법 순서는 각 퍼즐이 유지한다.
- MEOW 네 기법이 `_active_units()`로 고양이가 없는 후보 단위를 같은 순서로 읽는다.
  기존 상태 메서드를 감싼 중복 함수와 수동 교집합 반복문도 제거했다.
- MEOW 모순의 유무와 메시지는 `LogicSnapshot.contradiction_message()`에서 판정한다.
  논리 풀이의 결과 생성과 가정 풀이의 결정적 결과 처리도 합쳤다.
- 입력·재생·충돌 표시가 `BoardLayout.cell_rect/cell_at`으로 셀 좌표를 계산한다.
  전달만 하던 화면별 메서드를 제거했다. 버튼은 그릴 때 호버를 계산한다.
- 공통 runtime/font/DOM 검사는 공통 테스트에 모았다. 강화된 포커스/모바일 CSS 검사를
  양쪽 편집기에 적용하고 폰트 검사는 세 패키지 소스 문자를 함께 검사한다.

## 크기

Python 물리적 줄 수에는 빈 줄과 주석을 포함한다. 테스트를 실행 코드에 섞지 않는다.
AST 위치 수는 정적 구조 지표이며 실행 중 탐색 분기 수나 시간 복잡도가 아니다.

| 지표 | 변경 전 | 변경 후 | 차이 |
| --- | ---: | ---: | ---: |
| 실행 코드 | 6,954 | 6,874 | −80 |
| 테스트 | 4,084 | 4,103 | +19 |
| `if` 위치 | 439 | 428 | −11 |
| 조건식 | 53 | 54 | +1 |
| 명시적 반복문 | 131 | 132 | +1 |

공통 함수로 옮긴 코드도 변경 후 합계에 포함한다. 조건식으로 분기를 숨긴 수치는 아니다.

## 검증

- 변경 전 전체 검사348 passed, 1 skipped → 변경 후370 passed, 1 skipped.
  명령: `uv run --locked python -m pytest -q -W error`.
- `uv run ruff check .`, `uv run ruff format --check .`: 통과, Python107개 파일.
- 변경 전후 전체 결과/trace fingerprint51건 일치. 내장 프리셋12개, MEOW 정체/소형/고정 seed
  무작위 영역30개, Sudoku 유일해·복수해·해 없음·반증 후 해결·가정 복수해를 포함한다.
  해뿐 아니라 설명·근거·제외 순서·스냅샷·가정 라운드·최종 분류를 함께 비교했다.
- 변경한 다섯 finder는 각각 합성 상태600건에서도 기준 커밋의 반환값과 일치했다.
- 보드 픽셀 SHA-256은393건 모두 변경 전후가 같다. MEOW 전체 재생210개,
  Sudoku 전체 재생178개, 편집기5개(MEOW 크기1/8/26, Sudoku 선택/충돌)를 포함한다.
  한글 키가 손상된 JSON을 파싱한 초기244개 집계 대신 원본 해시393개를 순서대로 비교했다.
- 새 검사에서 구현 전 모순 메서드·단위 순회·격자 좌표·즉시 호버 처리가 실패함을 확인했다.
- `uv run --locked --group web python scripts/build_web.py`: 실제 양쪽 빌드 통과.
  APK의 Python 소스 MEOW35개/Sudoku32개를 확인했고 새 공통 제약 모듈 포함과 원본 바이트
  일치, 다른 퍼즐 패키지가 포함되지 않음을 확인했다.
- 실제 브라우저에서 MEOW 영역 입력/드래그, Sudoku 숫자 입력, 양쪽 예제 풀이·최종 단계·
  편집 복귀를 확인했다. 두 앱의 콘솔 오류는 없었다.
- 독립 전체 코드 검토: 수정이 필요한 문제 없음. 공통 함수가 퍼즐 패키지를 import하지
  않음을 AST로 확인했다. 원본 형제 저장소 두 개의 작업 트리도 깨끗하다.

기존 Windows 심볼릭 링크 권한 검사1개는 건너뛰었다. 모든 가능한 퍼즐, 모바일/다른
브라우저와 실제 OS 클립보드는 이번에 검사하지 않았다. 속도 개선을 목표로 한 변경은 아니다.
합성 상태600건의 pointing 미세측정은21.21→29.93ms로 호출 비용이 늘었고, 51개 전체
풀이/기록 비교는 변경 전1.24초, 변경 후1.07초였다. 이 단일 측정으로 속도 향상을 주장하지 않는다.

MEOW의 별도 제거 trace·독립 exact 검증과 Sudoku의 즉시 후보 전파·배치 추론·두 번째 해
탐색은 각 퍼즐에 남긴다. 이를 같은 루프로 만들려면 추가 상태 변환과 callback 계층이 필요하다.
로컬 브랜치에만 저장하며 GitHub 게시/원본 저장소 변경은 수행하지 않았다.
