# 불필요한 분기와 중복 축소

사용자 요청: 알고리즘과 퍼즐 고유 동작을 유지하면서 남은 중복과 불필요한 분기를 최대한 줄인다.

서로 다른 상태 모델을 하나의 솔버 엔진으로 강제하지 않는다. 후보가 한 단위에 모였을 때
다른 단위에서 제거하는 순수 집합 연산만 공유한다. 기법 우선순위, 최소 근거 수,
이미 배치된 고양이 확인, 설명과 기록은 기존 퍼즐 코드가 결정한다.

MEOW의 모순 판정은 하나의 상태 메서드로 모으고, 논리 풀이 결과와 가정 풀이의
반복 종료 처리를 합친다. 모순 메시지의 우선순위와 모든 가정 라운드를 보존한다.

입력과 재생의 셀 좌표/히트 검사는 BoardLayout이 담당한다. 버튼 호버는 그릴 때
현재 마우스 좌표로 계산해 중복 갱신 상태를 제거한다. 실제 색상·여백·그리는 순서는 유지한다.
공통 런타임·폰트·브라우저 입력 검사는 공통 테스트로 옮겨 중복을 없앤다.

새 의존성, 호환 래퍼, 앱 이름 분기, 새 옵션을 추가하지 않는다. 원본 두 저장소는
수정하지 않으며 GitHub에 게시하지 않는다.

검증 기준: 변경 전 51개 사례의 전체 결과와 풀이 기록 fingerprint가 변경 후와 같아야 한다.
대표 해만 비교하지 않고 설명·근거·단계 순서·분류·가정 라운드도 포함한다.
추가로 기법과 경계 조건의 집중 검사, 전체 pytest/Ruff, 실제 양쪽 웹 빌드를 실행한다.
라인 수와 AST if/반복문 위치 수는 구조적 감소의 보조 지표이며 탐색 복잡도를 뜻하지 않는다.
