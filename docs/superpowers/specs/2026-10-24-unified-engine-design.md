# 하나의 실행 규칙과 퍼즐 플러그인

사용자 요청: 두 솔버에 흩어진 처리를 하나의 일정한 규칙으로 만들고, 두 퍼즐은
거기에 데이터와 고유 코드만 넣도록 한다. 기존 알고리즘 우선순위와 퍼즐 동작은 유지한다.

## 결정한 구조

`puzzle_common.engine.Engine`이 논리 고정점, 후보 순서대로 한 단계 가정,
첫 결정적 가정에서 중단, 반증 적용과 재추론, 조용한 재귀 탐색을 모두 실행한다.
퍼즐별 솔버에 동일한 실행 루프를 남기지 않는다. 앱 이름에 따른 분기도 없다.

상태는 `clone`, `snapshot`, `find_contradiction`, `is_complete`라는 같은 계약을 갖는다.
불변 스냅샷과 추론 결과 자체는 기존 자료형을 유지한다. 퍼즐 플러그인은 순수 기법 선택,
검증된 추론 적용, 가정 후보 순위, 정체 이력, 가정 적용, 반증 추론 생성, MRV 후보와
해의 동등성 기준을 제공한다. 새로운 외부 의존성은 사용하지 않는다.

공통 결과 `LogicStep`, `LogicRun`, `ProbeRun`, `ProbeRound`, `SolveRun`이 실행 기록의
전달 규칙이다. MEOW와 Sudoku의 기존 공개 결과/설명은 이 기록에서 변환한다.
MEOW의 독립 exact 검증과 Sudoku의 두 번째 해 확인은 고유 정책으로 유지하며,
공통 탐색에 해 상한1/2를 전달한다. 해가 발견된 가정은 원본 상태를 덮어쓰지 않는다.

앱은 `PuzzlePlugin(create_editor, solve, create_player, get_draft)` 레코드 하나를 등록하고
공통 `run_app(plugin)`으로 실행한다. 별도 앱 수명주기 함수와 전역 퍼즐 레지스트리는
두지 않는다. 웹 번들은 선택된 퍼즐 패키지와 공통 코드만 포함한다.

## 반드시 보존할 순서

논리 루프는 모순 → 기법 검색 → 기법이 없을 때 완성 여부를 확인한다.
완성된 MEOW 보드에도 마지막 고양이의 명시적 제외 기법이 적용될 수 있다.
가정 후보는 라운드 시작에 고정하고, 정체만 기록하고 계속하며, 해결/모순에서 멈춘다.
모순이면 원본에 반증 추론을 적용하고 다시 고정점까지 진행한다. 후보가 없는 MEOW
라운드도 기록한다. Sudoku의 H1 점수 변경과 정체 후보 재시도 순서를 보존한다.

재귀 탐색은 같은 엔진의 논리와 가정 적용을 사용하되 화면 기록과 가정 이력을 만들지 않는다.
사람식 풀이의 해가 있으면 첫 해로 보존하고, 동등한 해는 중복으로 세지 않는다.
Sudoku는 이 경우에도 원본 상태에서 해2개까지 검사한다. 유일성 확인만 수행한 경우에는
화면에 탐색 전환 메시지를 추가하지 않는다.

## 검증

기준 d0fbd27: 전체370 passed, 1 skipped, 전체 결과/trace51건 지문을 저장했다.
공통 엔진은 작은 가짜 규칙으로 상태 전이/정지/분리/상한/중복을 검사한다.
두 퍼즐의 기존 검사와 공유 엔진 호출 검사, 전체51건 기록 일치, Ruff,
실제 양쪽 웹 빌드/번들/브라우저 동작과 독립 전체 검토를 완료한다.
원본 두 형제 저장소는 수정하지 않는다. GitHub 게시도 이번 작업에 포함하지 않는다.
