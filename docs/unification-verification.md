# 통합 검증 — 2026-10-23

## 범위

기존 기능과 화면을 유지하며 저장소·개발 환경·공통 UI/입력 코드·웹 빌드를 통합했다.
원본 두 저장소는 변경하지 않았고, 두 Git 이력은 통합 브랜치의 조상으로 보존했다.
작업 위치는 새 `puzzle-solvers` 폴더, 브랜치는 `codex/unify-puzzle-solvers`다.
루트 패키지 구조를 선택해 기존 `python -m meow`, `python -m sudoku` 명령을 유지했다.

## 자동 검사

| 검사 | 결과 |
| --- | --- |
| `uv lock --check` | 기존 외부 패키지 9개의 버전·잠금 항목 유지 |
| `uv run --locked ruff check --no-cache .` | 통과 |
| `uv run --locked ruff format --check --no-cache .` | 통과 |

| 데스크톱 모듈 진입점 | 두 앱 모두 dummy SDL로 시작 후 QUIT 정상 종료 |
| 퍼즐 코드 보존 | 모델·파서·솔버·카탈로그 21개 파일이 원본과 바이트 단위 일치 |
| 웹 번들 검사 | 각 APK에 공통 모듈·두 폰트·OFL 포함, 다른 앱·테스트·캐시 미포함 |
| 독립 전체 변경 리뷰 | 중요한 문제 없음 |

테스트 1개는 Windows에서 심볼릭 링크 생성 권한이 없어 건너뛰었다.
일반 경로 탈출·프로젝트/빌드 루트 삭제 방지 검사는 실행해 통과했다.

## 실제 브라우저 확인

로컬 `http://127.0.0.1:8765/`에서 두 앱 링크를 통해 각각 실행했다.

- MEOW: 한글 UI/폰트, 앱별 프롬프트, 잘못된 JSON의 오류·텍스트 보존,
  정상 4×4 영역 JSON, 10단계 유일해 완료, 단계 이동, 편집 복귀 후 원본 영역 유지 확인.
- Sudoku: 한글 UI/폰트, OCR 프롬프트, 객체 JSON의 형식 오류·텍스트 보존,
  정상 9×9 JSON, 16단계 유일해 완료, 단계 이동, 편집 복귀 후 원본 숫자 유지 확인.
- 두 실행에서 브라우저 error 로그 없음.

## 확인하지 않은 범위

새 GitHub 저장소 생성·푸시·실제 Pages 배포는 수행하지 않았다.
운영체제 클립보드는 기존 구현과 회귀 검사로 확인했으며, 사용자 클립보드를 직접 변경하지 않았다.
모든 기기·브라우저 조합과 심볼릭 링크 실제 삭제 방지는 여기서 실행하지 않았다.
공통 코드를 변경하면 두 앱에 영향을 주므로 전체 검사와 두 웹 빌드를 함께 실행해야 한다.
